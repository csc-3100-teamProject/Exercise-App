# Exercise App
[![CI Testing](https://github.com/csc-3100-teamProject/Exercise-App/actions/workflows/node.js.yml/badge.svg)](https://github.com/csc-3100-teamProject/Exercise-App/actions/workflows/node.js.yml)

The style guide we will use for now is based on the
default configuration of prettier which is

{"trailingComma": "es5",

"tabWidth": 4,

"semi": false,

"singleQuote": true
}

and the React/JavaScript style guide: https://airbnb.io/javascript/react/.
For setting up prettier on VsCode follow: https://blog.yogeshchavan.dev/automatically-format-code-on-file-save-in-visual-studio-code-using-prettier
and for IntellJi follow: https://www.jetbrains.com/help/idea/prettier.html#prettier_before_you_start.

Figma Link: https://www.figma.com/design/jAqtuf2LdNPl0aFrx7bWu9/Workout-Planner...?node-id=16-8&t=e4mua9m2qi1CbeiV-1

For MongoDB, make sure to run npm install dotenv on local machine if you haven't yet.
